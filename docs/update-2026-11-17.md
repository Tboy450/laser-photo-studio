# Studio update — November 17, 2026

This update brings the local Studio development history onto GitHub, including the previously unpublished ladder, position-recovery, timing, dwell and crawl work.

## Latest changes

- An editable **Laser-off return speed (mm/min)** control below scan direction. Suggested values include 4500, 5000 and 6000; whole values from 1–6000 are accepted. It changes row repositioning, not engraving feed or power. Existing presets keep their original return speeds. The chosen value is saved with presets/jobs and shown in job summaries. Thin-feature hops remain a separate setting.
- USB port discovery retains previously used ports, offers Refresh ports, explains the selector and distinguishes denied access from a confirmed busy port.
- Sample photos have structured Evidence, Surface and Settings records; missing metadata remains unknown and does not become a proven material recipe.
- Guide → About & contact credits **HASK**, explains the app's purpose and links to the public contact page.

## Known limitations and follow-up work

- The live completion estimate has been reported to jump by hours. This update records the issue; it does not fix the ETA algorithm.
- USB dropouts and recovery usability still require further work. The separate resizable recovery-dialog candidate is not part of this update.
- Faster returns have been checked offline. Machine positioning and finish quality at a chosen rate still require a physical test. Faster returns reduce the time between engraving strokes.
- Dwell and crawl tools are not evidence of a validated reflective-metal cutting or production recipe.
- The separate centered-tin geometry draft PR is not incorporated here.

No private messages, formulas, local machine settings, active recovery journal or customer portrait files are included. The bundled reflective-lid image is a technical sample with its limitations recorded. This source update does not restart an active Studio process or change an already running print.
